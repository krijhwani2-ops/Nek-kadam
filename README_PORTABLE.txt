NEK KADAM PORTABLE EDITION - INSTRUCTIONS
==========================================

How to use this on another PC:
1. Copy the entire 'nekkadam' folder to your Pendrive.
2. Plug the Pendrive into the new PC.
3. Ensure the new PC has Node.js installed (if not, download from nodejs.org).
4. Double-click the 'RUN_NEK_KADAM.bat' file inside the folder.
5. The app will start, detect the new PC's IP, and show the URL for mobile access.

Data Safety:
- All data is saved inside the 'nekkadam.db' file in this folder.
- When you move the pendrive, the data moves with it!
